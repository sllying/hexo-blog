字幕交付前，我会检查时间轴、换行和音画同步

SLLYING2026.09.082 分钟阅读

字幕文本正确只是起点。时间轴、中文断句、字体缺失和封装结果都需要在成片里检查，不能只看编辑器里的预览。

这篇由媒体项目梳理任务延伸为一份技术检查笔记。可访问摘要没有保留完整处理过程，所以不把下面的步骤写成某次已交付视频的执行记录。

先确定字幕与媒体的时间基准

检查媒体时长、起始时间和音轨，再确认字幕是按同一版本制作的。剪掉片头、变速或替换音轨后，旧字幕可能每一条都合法，却整体偏移。

ffprobe -v error -show_entries format=duration,start_time \
  -show_entries stream=index,codec_type,codec_name \
  -of json input.mp4

命令使用示例文件名，输出需要结合实际媒体解释。容器时长和各流时长不同并不一定是损坏，也可能来自编码延迟或时间戳处理。

检查的不只是错别字

重点抽检专有名词、数字和否定词；检查字幕是否结束过早、是否跨镜头停留过久，以及两条字幕是否意外重叠。中文换行尽量保留语义单位，避免把一个短语拆在两行。

从最终文件里看结果

软字幕要检查播放器兼容与默认轨，硬字幕要检查字体、描边和安全边距。输出后回看开头、中段、结尾和快速对话段，并验证音画同步。成片附上字幕版本、工具版本和源文件校验记录，后续修改才能找到对应输入。
