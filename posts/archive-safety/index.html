解压之前，先检查文件清单和路径

SLLYING2023.01.292 分钟阅读

一个合法压缩包也可能包含越界路径、异常展开体积或符号链接。先做清单检查，再把内容写进独立目录。

这是旧站压缩包主题的重新整理。压缩包是一组外部提供的路径和字节，不能因为它能被工具打开，就让里面的文件直接覆盖工作区。

路径要按目标平台校验

import path from "node:path";

function targetInside(root, entryName) {
    const target = path.resolve(root, entryName);
    const relative = path.relative(root, target);
    if (relative === ".." ||
        relative.startsWith(".." + path.sep) ||
        path.isAbsolute(relative)) {
        throw new Error("Archive entry escapes destination");
    }
    return target;
}

这个示例只展示解析后的目录包含关系，不能单独构成完整安全解压器。还需要拒绝不需要的绝对路径和驱动器路径，处理不同分隔符、符号链接、硬链接、大小写碰撞与目标目录已有链接。成熟归档库的限制选项应当优先使用。

对展开量设上限

不要只看压缩文件大小。限制文件数量、单个文件大小、累计展开大小和压缩比，在实际解压流中继续计数；头部声明值和真实输出都可能不可靠。遇到异常时，删除本次独立临时目录，不继续移动部分产物。

先验收，再进入工作区

列出清单，确认来源与预期内容，在新目录解压，检查结果后再移动到目标位置。恢复备份还需要应用级校验，例如数据库能否打开、manifest 是否一致、媒体引用是否完整。
